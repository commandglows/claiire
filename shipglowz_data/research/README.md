# Wispr Flow Data - Claiire

This directory is the canonical staging area for migrated inspiration and reference corpora that must not live inside product source trees.

## Current Corpus

- `app-inspiration/`: archived references, prototypes, briefs, game notes, and legacy BMAD output previously stored under `app/Inspiration/`

## Classification Rule

- business or product references stay here until they are synthesized into canonical docs under `shipglowz_data/business/`
- technical references stay here until they are synthesized into canonical docs under `shipglowz_data/technical/`
- prototype code stays here as research material, not active source
- nothing in this directory should be imported or treated as production code
