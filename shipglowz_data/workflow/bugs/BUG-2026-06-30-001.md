## Reproduction

- Preconditions:
  - Claiire monorepo after the cleanup migration
  - Local validation mode from `CLAUDE.md`
- Steps:
  1. Run `pnpm --filter claiire build` from the monorepo root.
  2. Run `cd site && ./node_modules/.bin/astro build`.
  3. Run `cd app && ./node_modules/.bin/jest --runInBand`.

## Expected Behavior

- Root proof commands should execute without a pnpm build-script policy blocker.
- Astro should build with Clerk-auth surfaces enabled in configuration.
- App unit tests should execute under one coherent Jest 30 runtime.

## Observed Behavior

- `pnpm --filter claiire build` stops before the build because `pnpm-workspace.yaml` contains unresolved `allowBuilds` placeholders.
- Direct Astro build fails on unresolved import `virtual:@clerk/astro/config`.
- Direct Jest run fails before tests execute with `this._moduleMocker.clearMocksOnScope is not a function`.
